# DESIGN.md — CCTV Vision & Memory Corruption Studio

> Official Design Direction & Anti-Slop Specifications  
> **Dials**: ENERGY 2 / RHYTHM 1 / MOTION 1

---

## 1. Identity & Purpose
- **Product**: CCTV Vision & Memory Corruption Studio
- **Archetype**: Specialized Computer Vision & Forensic Digital Art Station
- **Visual Language**: Precision Industrial Machine-Vision, Optical Surveillance Telemetry, and Stepped 8-Bit Memory Corruption Glitch.
- **Core Principle**: Every visual element corresponds to a real computer-vision parameter, coordinate system, or memory fault register. Zero decorative filler.

---

## 2. Dials Specification (Anti-Slop Part 3)
- **ENERGY: 2 (Balanced)**  
  High-visibility technical contrast without loud marketing hype. Avoids generic blue-purple gradients, floating orbs, or gratuitous glowing badges.
- **RHYTHM: 1 (Uniform Studio Grid)**  
  A stable, professional 3-pane workbench: Top Telemetry Bar, Left Parameter Matrix, Center High-DPI Viewport, and Bottom Coordinate Inspector.
- **MOTION: 1 (Functional & Tactile)**  
  Smooth, cursor-anchored mouse wheel zoom, 2D translation panning, and crisp modal transitions. Zero floating or bouncing animations.

---

## 3. Color System
- **Dark Mode (Default)**:
  - Deep Matte Foundation: `#06080c` (viewport mat) and `#0c1017` (surfaces)
  - Dividers & Outlines: `#1e293b` (slate-800) and `#334155` (slate-700)
  - Primary Text: `#f8fafc` (slate-100)
  - Secondary Text: `#cbd5e1` (slate-300, contrast > 7:1)
- **Light Mode (Forensic Lab)**:
  - Clean Matte Foundation: `#cbd5e1` (viewport mat) and `#ffffff` (surfaces)
  - Dividers & Outlines: `#cbd5e1` (slate-300)
  - Primary Text: `#0f172a` (slate-900)
  - Secondary Text: `#334155` (slate-700, contrast > 7:1 WCAG AA)
- **Telemetry Accent**: `#06b6d4` (Cyan) for camera status and sensors.
- **Dynamic Glitch Palettes**: Tokyo Lavender, Acid Yellow, Cyber Electric Blue, Matrix Green, Neon Magenta, Glitch Coral, and Terminal Monochrome.

---

## 4. Typography
- **Technical Telemetry**: `JetBrains Mono`, `Share Tech Mono`, and system monospace. Used strictly for machine vision coordinates, confidence values, hexadecimal crash dumps, and telemetry timestamps.
- **Interface Controls**: System UI Sans (`Inter`, `-apple-system`, `Segoe UI`) for crisp, legible button labels and settings sliders.

---

## 5. Purpose of Key Visual Techniques (Purpose-Gate Compliance)
1. **Thin Bounding Boxes & Corner Brackets (`⌜ ⌝ ⌞ ⌟`)**: Replicates authentic object detection reticles from machine-vision frameworks (YOLO, MediaPipe, OpenCV).
2. **Red Tracking Crosses (`+`)**: Marks detected feature centroids (landmarks, joint coordinates, facial anchors).
3. **Stepped Pixelation Blocks**: Recreates the visual signature of low-level visual data memory failures (buffer corruption / memory page fault).
4. **Embedded Diagnostic Code**: Displays authentic hexadecimal exception dumps (`MEM_ERR 0x03DF`, `PAGE_FLT_0109`, `DATA_SEG_A`).
5. **No Slop Background Grid**: The canvas viewport uses an authentic matte surface to ensure the image being analyzed is the sole focal hero.
